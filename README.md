# AlonSpace — אתר חדש (Node.js + Express)

אתר אינטראקטיבי מלא ל-AlonSpace (משרדים פרטיים במגדלי אלון, ת"א), בנוי מחדש עם Node.js, Express ו-EJS, במקום ה-WordPress הקיים.

## מה יש באתר

- **כל התוכן מהאתר הקיים** — דף הבית, אודות, המתחם והשירותים, המלצות, שאלות נפוצות, גלריה, יצירת קשר — כתוב מחדש ומעוצב מחדש (מוטיב "טבעות עץ" בהשראת השם "אלון").
- **קביעת סיור אינטראקטיבית** — לוח שעות אמיתי (`/הזמנת-סיור`) שבודק זמינות בזמן אמת ושומר הזמנות במסד נתונים.
- **טופס יצירת קשר** ששומר פניות ושולח מייל התראה (אם מוגדר SMTP).
- **המלצות דינמיות** — מבקרים יכולים לשלוח המלצה, והיא מתפרסמת רק לאחר אישור ידני.
- **פאנל ניהול** (`/admin`) עם התחברות מוגנת, לניהול סיורים, הודעות והמלצות.
- מסד נתונים SQLite מקומי (קובץ יחיד, אין צורך בשרת DB נפרד).

## הרצה מקומית

```bash
npm install
cp .env.example .env     # ואז לערוך את .env ולמלא סיסמאות
npm start
```

האתר יעלה בכתובת `http://localhost:3000`.

פאנל הניהול: `http://localhost:3000/admin`
בהפעלה ראשונה נוצר אוטומטית משתמש ניהול (ברירת מחדל `admin` / `alonspace2026`, או לפי `ADMIN_USERNAME`/`ADMIN_PASSWORD` ב-`.env`). **חשוב להחליף את הסיסמה לפני עלייה לאוויר.**

## משתני סביבה (`.env`)

ראו `.env.example` להסבר מלא. החשובים ביותר:

| משתנה | מה זה |
|---|---|
| `SESSION_SECRET` | מחרוזת אקראית וסודית לאבטחת הסשנים — חובה לשנות |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | פרטי הכניסה לפאנל הניהול |
| `SMTP_HOST/PORT/USER/PASS` | הגדרות שרת מייל לשליחת התראות. אם לא מוגדר — הטפסים עדיין עובדים ונשמרים במסד הנתונים, רק לא נשלח מייל |
| `CONTACT_EMAIL` | לאן להעביר את ההתראות |

## פריסה (Deploy) ל-Render / Railway

שני השירותים תומכים ב-Node.js "out of the box":

1. דחפו את התיקייה הזו ל-repo ב-GitHub.
2. ב-Render: **New → Web Service** → מחברים את ה-repo → Build command: `npm install`, Start command: `npm start`.
   ב-Railway: **New Project → Deploy from GitHub repo** — הוא מזהה אוטומטית שזה פרויקט Node.
3. מוסיפים את משתני הסביבה מ-`.env.example` בהגדרות השירות (לשונית Environment/Variables).
4. **חשוב:** מסד הנתונים הוא קובץ SQLite בתיקיית `data/`. בשני השירותים יש להוסיף **Persistent Disk / Volume** שמצביע לתיקיית `data/`, אחרת הנתונים יימחקו בכל פריסה מחדש.
5. מחברים את הדומיין `alonspace.co.il` דרך הגדרות ה-Custom Domain של השירות, ומעדכנים רשומות DNS (CNAME/A) אצל ספק הדומיין שלכם.

## לגבי התמונות

התמונות באתר כרגע מקושרות ישירות (hotlink) מהאתר הקיים ב-`alonspace.co.il/wp-content/uploads/...`, כפי שביקשתם. כדאי בעתיד להעלות אותן לתיקיית `public/images/` ולעדכן את הנתיבים ב-views וב-`db.js`, כדי שהאתר החדש לא יהיה תלוי בזמינות האתר הישן.

## מבנה הפרויקט

```
server.js            נקודת הכניסה
db.js                הגדרת מסד הנתונים + seed נתונים ראשוני
lib/slots.js          לוגיקת שעות פנויות לסיורים
lib/mailer.js          שליחת מיילים (nodemailer)
routes/pages.js        כל הדפים הציבוריים
routes/api.js           API: טפסים, שעות פנויות
routes/admin.js          פאנל ניהול
views/                  תבניות EJS
public/                 CSS, JS, נכסים סטטיים
data/                   קובץ ה-SQLite (נוצר אוטומטית)
```

## התאמות עתידיות מומלצות

- להחליף תמונות hotlinked בתמונות מקומיות/מותאמות.
- להוסיף Google Analytics / Meta Pixel אם רוצים מעקב שיווקי.
- לחבר תשלומים/חתימת חוזה דיגיטלית אם רוצים לסגור עסקה ישירות באתר.
- להוסיף `robots.txt` ו-sitemap.xml לצורך SEO (האתר הישן היה עם `noindex, nofollow` — כדאי לוודא שהאתר החדש כן מאונדקס).
